# Task brief

Use this template when sending a worker a task, and paste [worker-brief.md](worker-brief.md) in full. Small, already-decided changes (such as a typo, rename, or dictated wording) can skip fields that don't apply.

```markdown
- **Source:** <verbatim comment text and URL, user request, or finding>
- **Claims and evidence:** <for each claim, command and output, or "not reproduced">
- **Task:** <state the problem and ask whether code, tests, or docs must change, or give the exact change when already decided>
- **Constraints:** <branch, scope, push, and reply rules>
```
