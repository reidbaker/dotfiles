# PR Comment Replies Across All Repositories

- Across **all** repositories, agents may post replies directly on GitHub **only** to:
  1. Your comments (`reidbaker`, unless clearly addressed to someone else).
  2. Bot comments — either from a bot account or from a human account when the comment carries an explicit bot/agent marker (for example, a trailing `🤖 Agent-generated` / `<!-- agent-generated -->` suffix).
- For human-written comments from anyone else, make any warranted code changes and **draft the reply locally** for you to review/post — never post a reply directly on GitHub.
- When in doubt whether a comment was written by a human or generated by a bot, treat it as human-written and draft the reply locally.
