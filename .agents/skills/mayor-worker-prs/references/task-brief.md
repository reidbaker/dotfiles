# Task brief

Fill in every field below whenever you send a worker a task, and paste [worker-brief.md](worker-brief.md) in full too.

```markdown
- **Source:** <verbatim comment text and URL, or the audit file and section>
- **Claims and evidence:** <for each claim, "reproduced: <command, output>" or "not reproduced">
- **Question for the worker:** Can the code still produce this outcome? What must change: code, tests, docs?
- **Constraints:** <branch, push, and reply rules>
```

A brief missing a field is not ready to send.
